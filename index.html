❓ ¿Cómo activo la ubicación si no funciona?
Android / Chrome: toca el candado o la "i" junto a la dirección web arriba → Permisos del sitio → Ubicación → Permitir. Si sigue sin ir, revisa también Ajustes del móvil → Aplicaciones → Chrome → Permisos → Ubicación → Permitir.
iPhone / Safari: Ajustes del iPhone → Safari → Ubicación → Preguntar o Permitir. También Ajustes → Privacidad → Localización → Safari → Al usar la app.
Después de cambiarlo, vuelve a esta página y pulsa otra vez "Capturar ubicación actual".
